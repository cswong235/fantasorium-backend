Fantasorium API

The backend for Fantasorium. All requests and responses use JSON.

Authentication

Routes marked 🔒 Requires login need the access_token from /login or /signup, sent as a header:

Authorization: Bearer <access_token>

A missing or invalid token returns 401 Unauthorized.

General

GET/health

Checks that the server is running.

{ "status": "ok" }

Accounts

POST/signup

Creates an account and logs it in.

{ "email": "tester@example.com", "password": "password123" }

Returns 201 with { user, session }. Returns 409 if the email is already in use.

POST/login

Logs in with an email and password.

{ "email": "tester@example.com", "password": "password123" }

Returns { session }. Use session.access_token for the routes below. Returns 401 on wrong details.

GET/profile 🔒 Requires login

Returns the logged in user.

{ "id": "...", "username": "tester", "created_at": "..." }

GET/users 🔒 Requires login

Returns every user except yourself, as an array of { id, username, created_at }.

Posts

GET/posts 🔒 Requires login

Returns posts you can see, newest first: all public posts, your own posts, and friends-only posts from people who sent you a friend request that you accepted. Each post includes the author's username.

QueryDescription
limitOptional. How many posts to return. Leave out to get every post.
offsetOptional. How many posts to skip. Defaults to 0.

Example: /posts?limit=3&offset=3 returns the 4th to 6th newest posts.

POST/posts 🔒 Requires login

Creates a post. content is required, image is optional.

{
  "title": "My first quest",
  "content": "Rolled a natural 20!",
  "visibility": "public",
  "image": "https://...supabase.co/storage/v1/object/public/post-photos/..."
}

visibility is "public" or "friends_only". Returns 201 with { message, result }.

Friendships

A friendship starts as pending when sent, then the receiver changes it to accepted or rejected.

GET/friendships 🔒 Requires login

Returns every friendship you're part of, whether you sent it or received it.

[{ "id": 1, "user_id": "sender id", "friend_id": "receiver id", "status": "pending", "created_at": "..." }]

POST/friendships 🔒 Requires login

Sends a friend request. It's saved with a pending status.

{ "friend_id": "id of the user to friend" }

Returns 201 with { message, result }.

PATCH/friendships/:id 🔒 Requires login

Accepts or rejects a request sent to you. :id is the friendship's id.

{ "status": "accepted" }

status must be "accepted" or "rejected", otherwise 400. Returns 404 if there's no pending request with that id sent to you.

DELETE/friendships/:id 🔒 Requires login

Removes a friendship, whoever sent it. :id is the other user's id, not the friendship's id.

Returns { message, result }, or 404 if there's no friendship with that user.

Errors

Errors come back as { "error": "message" }. Unknown routes return 404 with { "error": "Route not found" }.
